# pyGWRetrieval Examples

Two self-contained example sets, each with its own README:

| Example | What it shows |
|---------|---------------|
| [**`ucrc/`**](ucrc/README.md) — Upper Colorado River Basin | Large-area retrieval (Water Data OGC API), unconfined-aquifer filtering, and gridded **water-table depth mapping** with a five-method interpolation comparison. |
| [**`msa_analysis/`**](msa_analysis/README.md) — Metropolitan analysis & general usage | A regional groundwater **case study across 9 U.S. metropolitan areas** (`full_workflow_csv_zipcodes.py`) plus general-purpose usage scripts (basic usage, temporal analysis, spatial queries, multi-source). |

See each folder's README for details, how to run, and outputs.
